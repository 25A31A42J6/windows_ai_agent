# 🤖 Windows AI Agent

An AI-powered Windows system assistant built with **Python, Ollama, and Strands Agents**.

The agent can interact with the Windows system, retrieve system information, monitor resources, inspect processes, network connections, services, and provide useful system administration assistance through natural-language commands.

---

## 🚀 Features

- 🤖 AI-powered conversational system assistant
- 🪟 Windows system information
- 💻 CPU and memory monitoring
- 💾 Disk usage information
- ⚙️ Running process inspection
- 🌐 Network configuration and connections
- 🔌 Open TCP connections and ports
- 🛠️ Windows service information
- 🕐 Real-time information
- 🌦️ Weather information
- 🌫️ Air Quality Index (AQI)
- 🔎 Step-by-step troubleshooting
- 💬 Natural-language interaction

---

## 🧠 Technologies Used

- **Python**
- **Strands Agents**
- **Ollama**
- **Large Language Models (LLMs)**
- **PowerShell**
- **REST APIs**
